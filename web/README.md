# Aplicación web (Laravel)

Panel en tiempo real, API REST, agente y acceso con email y contraseña.

La documentación general del proyecto está en [../README.md](../README.md) y la guía de despliegue en [../docs/despliegue.md](../docs/despliegue.md).

Comandos principales:

```bash
php artisan migrate --seed
php artisan test
php artisan scramble:export --path=../docs/openapi.json
```
